# Graphtec test 01 — печать + резка для test_A

**Статус:** `SANDBOX_RESEARCH_ONLY`. Лабораторный эксперимент для пробы на реальном плоттере, не production-адаптер. Исходные файлы не изменяются.

## Что это

Пара файлов для одного листа Graphtec 450 × 320 мм, собранная из контрольного образца test_A:

| Файл | Назначение |
|---|---|
| `out/graphtec_print_test_A_grid.pdf` | Печать: 15 копий artwork (сетка 5 × 3) и две метки K100 из шаблона. Слои реза и отверстий удалены, обёртки optional content сняты |
| `out/graphtec_cut_test_A_grid.ai` | Резка: Adobe Illustrator 8, один слой. Две метки (залитые K100) и 30 замкнутых контуров Безье: по каждому изделию сначала отверстие, затем наружный контур |
| `out/graphtec_cut_test_A_grid_preview.pdf` | Те же метки и контуры в однослойном PDF — запасной путь: открыть в Corel и экспортировать в AI8 самим |
| `out/overlay_print_plus_cut.png` | Рендер печати, поверх — резка (пурпурный), отверстия (зелёный), поле ножа (синий пунктир), метки (оранжевый), порядок реза |
| `out/report.md` | Отчёт независимой проверки |
| `out/placement.json` | Размещение: смещения экземпляров, порядок реза, параметры |

## Входные данные

- `inputs/test_A_split_layers.pdf` — образец со слоями `Print`, `CutContour` (100% M), `Holes` (C + Y). Совпадает с fixture старой лаборатории.
- `inputs/graphtec_template.pdf` — шаблон Graphtec: метки 5 × 5 мм (центры 47,6 и 422,6 мм от левого края, 8,52 мм от нижнего) и поле ножа 417 × 300 мм.
- `inputs/pfi_blade_b2_template.pdf` — шаблон PFI Blade B2 (Duplo), для следующих тестов.

## Как запустить

```bash
python -I build.py --sample inputs/test_A_split_layers.pdf --template inputs/graphtec_template.pdf --out-dir out
python -I check.py --lab-dir .
```

Нужны `pikepdf`, `pypdfium2`, `Pillow`. PyMuPDF не используется.

## Принятые решения и допущения

- **Раскладка:** сетка 5 × 3, зазор между контурами 4 мм (по 2 мм bleed на изделие), сетка по центру поля ножа. Поворот 0°, без отражения.
- **Кривые:** контуры Безье переносятся из исходника без разбиения. Каждый контур явно замкнут (`s`): AutoClose не нужен.
- **Порядок реза:** столбцами от **левого** края листа, внутри столбца змейкой; отверстие режется перед наружным контуром. **Допущение:** передним краем при подаче считается левый (широкое поле 28 мм). Если это не так, пересоберите с `--lead right|top|bottom`.
- **Длинные прямые резы:** нет (максимальный прямой рез 0 мм — только окружности).
- **Метки:** геометрия скопирована из шаблона без изменений и одинакова в печати и в резке (проверка K1).
- **AI8:** файл без встроенных procset-ресурсов Illustrator. Программы резки обычно читают только операторы путей; если программа Graphtec файл не откроет, используйте `graphtec_cut_test_A_grid_preview.pdf` через Corel → AI8.
- **Печать:** CMYK исходника сохранён, PDF/X и OutputIntent не добавлялись.

## Результат проверки

Все 10 проверок K1–K10 пройдены (см. `out/report.md`): метки совпадают до 0,00001 мм, зазор между контурами 4,000 мм, все контуры внутри поля ножа с запасом 5,5 мм, печать и резка совпадают, в печати нет линий реза.

Расстояние от запечатываемой области до краёв листа: слева 31,6 мм, справа 8,4 мм, сверху 32,0 мм, снизу 42,0 мм. Метки печатаются в 6,0 мм от нижнего края — проверить, что на C7 это не слепая зона.

## Что проверить на машине

1. Открывает ли программа Graphtec файл AI8 напрямую.
2. Находит ли плоттер метки и попадает ли рез в печать (совмещение).
3. Порядок реза: от того ли края начинает, режет ли отверстие раньше контура.
4. Печать на C7: метки и изделия в запечатываемой области.
